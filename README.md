# Trade & Craft — Neon + Netlify 기초 웹앱

## 포함 기능
- 1~6모둠 화면, 교사 통합 현황판
- Neon PostgreSQL 저장 및 여러 기기에서 4초 간격 상태 갱신
- 중앙 은행 자원 구매/판매
- 가공품 제작 및 점수 집계
- 무역 제안 발송, 수락/거절, 거래 내역
- 교사 타이머 UI와 게임 초기화 기초 구조

## 배포 전 반드시 확인할 점
1. Neon 프로젝트를 만들고 SQL Editor에서 `schema.sql`을 한 번 실행합니다.
2. Netlify에 이 폴더를 배포합니다. Git 연결 배포라면 이 폴더의 파일을 저장소 루트에 둡니다.
3. Netlify Site configuration → Environment variables에서 `DATABASE_URL` (Neon 연결 문자열)과 `TEACHER_PIN` (교사 인증 번호)을 설정합니다.
4. 환경 변수를 바꾼 뒤 새 배포를 실행합니다.

## 현재 MVP의 한계
- 무역 제안 수락은 합의 상태만 저장하며 자원/코인의 자동 이동은 아직 구현하지 않았습니다. 학생이 서로 무엇을 주고받는지 합의한 뒤 교사가 확인할 수 있는 기초 단계입니다.
- 타이머는 서버의 실행 상태를 저장하지만 실제 초 단위 감소는 아직 UI/서버 통합 보완이 필요합니다.
- 교사 인증은 배포 전 보강이 필요한 기초 구현입니다. 교사 기능은 학생에게 공개하지 말고, 실제 수업 배포 전에 서버 측 세션 인증과 역할 검증을 추가하세요.
- 이 버전은 기존 DB를 건드리지 않고 신규 테이블만 만듭니다. 기존 Neon DB를 사용 중이면 SQL 실행 전 테이블 이름이 겹치는지 확인하세요.

## 보안
- `DATABASE_URL`과 `TEACHER_PIN`을 HTML/JavaScript 파일에 직접 넣지 마세요.
- 학생이 임의로 모둠 번호를 바꿀 수 있는 구조이므로, 실제 수업에서 사용할 때는 모둠별 접속 코드/서버 인증을 추가하는 것이 좋습니다.
